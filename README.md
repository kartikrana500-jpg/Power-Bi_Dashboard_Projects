Project 1:
🍕 Pizza Sales Dashboard – Power BI

 📊 Project Overview

This project is an interactive **Pizza Sales Dashboard** created using **Microsoft Power BI**. The dashboard analyzes pizza sales data to identify sales trends, customer preferences, best-selling pizzas, and overall business performance.

The goal of this project is to transform raw pizza sales data into meaningful and interactive visual insights that can help a business understand its sales performance and make better decisions.

 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query – Data cleaning and transformation
* DAX – Calculated measures and KPIs
* Data Visualization
* Excel / CSV Dataset

 📌 Key KPIs

The dashboard provides important business metrics such as:

* 💰 Total Revenue
* 🛒 Total Orders
* 🍕 Total Pizzas Sold
* 📦 Average Order Value
* 🍕 Average Pizzas Per Order

 📈 Dashboard Analysis

The dashboard includes analysis of:

 1. Daily & Monthly Sales Trends

Analyze how pizza sales and orders change over different days and months.

 2. Sales by Pizza Category

Compare sales performance across different pizza categories such as Classic, Supreme, Chicken, and Veggie.

 3. Sales by Pizza Size

Analyze customer preferences based on pizza size, such as Small, Medium, Large, and Extra Large.

 4. Top-Selling Pizzas

Identify the pizzas generating the highest number of orders and sales.

 5. Bottom-Selling Pizzas

Identify pizzas with comparatively lower sales performance.

 6. Sales by Day

Understand which days of the week generate the highest number of orders.

 7. Sales by Month

Analyze monthly revenue and order trends to identify high- and low-performing periods.


 🔄 Data Preparation

The raw dataset was processed using **Power Query** before creating the dashboard.

The data preparation process included:

* Removing unnecessary data
* Checking for missing values
* Handling duplicate records
* Correcting data types
* Creating required calculated columns
* Preparing the dataset for analysis

 🧮 DAX

DAX measures were created to calculate important business KPIs such as:

* Total Revenue
* Total Orders
* Total Pizzas Sold
* Average Order Value
* Average Pizzas Per Order

 🎨 Dashboard Features

* Interactive charts and graphs
* KPI cards
* Category-wise analysis
* Time-based analysis
* Pizza size analysis
* Top and bottom product analysis
* Interactive filters/slicers
* Business-focused visualizations

 📂 Project Files

* `pizza_sales dashboard.pbix` – Power BI dashboard file
* `README.md` – Project documentation
* Dataset – Source pizza sales data used for analysis

 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Use the available slicers and filters to interact with the dashboard.
4. Explore the different visualizations to analyze pizza sales performance.


 💡 Project Objective

The main objective of this project is to demonstrate practical skills in:

* Data cleaning
* Data transformation
* Data modeling
* DAX calculations
* Data visualization
* Business analysis
* Dashboard development using Power BI

 🍽️ Zomato Restaurants Analysis – Power BI

 📌 Project Overview

The Zomato Restaurants Analysis Dashboard is an interactive Power BI dashboard developed to analyze restaurant data, cuisines, ratings, locations, table booking availability, and online delivery services.

The dashboard transforms restaurant data into interactive visualizations that help understand restaurant distribution, customer ratings, cuisine preferences, and available restaurant services.

 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization
* Data Analysis

 📊 Key KPIs

The dashboard provides an overview of important restaurant metrics including:

* 🍽️ Total Restaurants
* 🍴 Total Cuisines
* 🌍 Total Countries
* 🏙️ Total Cities
* ⭐ Ratings

 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

* 📅 Year
* 🌍 Country

These filters allow users to explore restaurant information for different years and countries.

 📈 Dashboard Analysis

1. Table Booking Analysis

A donut chart analyzes restaurants based on table booking availability.

This helps understand how many restaurants provide table booking facilities compared with those that do not.

 2. Restaurants by City

A bar chart analyzes the number of restaurants across different cities.

This helps identify cities with a higher concentration of restaurants.

 3. Restaurant Cuisine & Ratings Analysis

A combination chart analyzes restaurants based on:

* Number of cuisines
* Restaurant ratings

This helps compare restaurant offerings with their rating performance.

 4. Online Delivery Analysis

A donut chart analyzes restaurants based on online delivery availability.

This provides insight into how many restaurants offer online food delivery services.

 5. Restaurants by Cuisine

A bar chart analyzes the number of restaurants across different cuisines.

This helps identify the most common and popular cuisine categories within the dataset.
